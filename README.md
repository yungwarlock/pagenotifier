# Page Notifier Chrome Extension

A simple extension to notify you if a chrome tab just changed. This is useful for websites that may not support
push notifications when something changes in the app.

## How to Use

To install and use this extension, follow these steps:

1. Clone the repository to a special folder on your machine.

```bash
git clone https://github.com/yungwarlock/pagenotifier
```

2. Open your Chrome browser or any chromium-based browser and navigate to `chrome://extensions`.

3. Enable Developer Mode on it

4. Click on the "Load unpacked" button and select the repository's folder.

5. The "Page Notifier" extension should now appear in your list of extensions.


## Usage

1. Go to any web page you wish to monitor.
2. Click on the "Page Notifier" icon in your Chrome toolbar.
3. Click the "Start Watching" button. The status indicator in the popup will change to "Watching".

If anything changes on the page while you're away from it, you get a desktop notification.
